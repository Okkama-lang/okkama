# Приложение B. Встроенные действия

Значения встроенных типов отвечают на фиксированный набор действий без всякого
импорта. Это приложение перечисляет их так, как их знает компилятор версии
0.6.2 (его таблица сигнатур встроенных действий). «same» в списке параметров
означает значение того же типа, что и получатель; `T`, `K` и `V` — тип
элемента массива и типы ключа и значения словаря. Двум действиям нужна
стандартная роль в области видимости, потому что их результат — тип этой роли:
`order(other)` возвращает `Order` из модуля `compare` (импортируйте `Order`), а
`cursor()` у массива возвращает `Cursor<T>` из `collections/iteration`
(импортируйте `Cursor`). Без импорта компилятор называет нужный импорт
(issue #952).

## B.1 Числа

| Действие | `int` | `byte` | `rat` | `float` |
|---|---|---|---|---|
| `abs()` | `int` | — | `rat` | `float` |
| `sign()` | `int` | — | `int` | `int` |
| `pow(n)` | `int`; `n` — неотрицательный `int` | — | `rat`; `n` — `int`, отрицательный обращает | `float`; `n` — `float` |
| `sqrt()` | `float` | — | — | `float` |
| `min(same)`, `max(same)` | `int` | — | — | `float` |
| `clamp(low, high)` | `int` | — | — | `float` |
| `less`, `less_or_equal`, `greater`, `greater_or_equal` (same) | `bool` | `bool` | `bool` | `bool` |
| `order(same)` | `Order` | `Order` | `Order` | `Order` |
| `numerator()`, `denominator()` | — | — | `int` | — |
| `int()` | `int` | `int` | отбрасывает дробную часть | отбрасывает дробную часть |
| `byte()` | ошибка вне 0..255 | `byte` | отбрасывает дробь, затем проверяет | отбрасывает дробь, затем проверяет |
| `float()` | ближайшее | ближайшее | ближайшее | `float` |
| `rat()` | точно | точно | `rat` | кратчайшая десятичная запись, точно |
| `char()` | кодовая точка | — | — | — |
| `string()` | каноническая запись | каноническая запись | `1/3` или `3` | кратчайшая запись, читаемая обратно без потерь |

У `float` есть ещё одиннадцать действий, каждое даёт `float`: `floor()`,
`ceil()`, `round()` (половина — от нуля), `trunc()`, `exp()`, `ln()`, `log2()`,
`log10()`, `sin()`, `cos()` и `tan()`, а также `atan2(other)` — угол точки
`(self, other)`. `finite()` и `nan()` отвечают `bool`; для float в Okkama они
всегда `true` и `false` (раздел 5.5). Каждый результат float обязан быть
конечным, иначе операция завершается ошибкой.

У `int` и `byte` есть семь общих битовых действий над окном фиксированной
ширины — 64 бита у `int` и 8 у `byte` (раздел 5.3): `bit_count()`,
`leading_zeros()` и `trailing_zeros()` дают `int`; `rotate_left(n)`,
`rotate_right(n)`, `reverse_bits()` и `swap_bytes()` дают значение типа
получателя.

Операторы над числами: `+`, `-`, `*` и `%` сохраняют категорию, два `byte`
дают `int`, а `/` над двумя `int` даёт `rat`. `==`, `!=`, `<`, `<=`, `>` и `>=`
сравнивают два значения одной категории. `&`, `|`, `^`, `~`, `<<`, `>>` и
`>>>` работают с `int` и `byte`. Смешение категорий — везде ошибка
компиляции.

## B.2 `bool` и `char`

| Получатель | Действия |
|---|---|
| `bool` | `string()` даёт `"true"` или `"false"` |
| `char` | `code()` даёт кодовую точку как `int`; `order(char)` даёт `Order`; `string()` даёт строку из одного символа |

`bool` принимает `!`, `&&` и `||`; у `char` нет `less` и нет `<` (issue #953).

## B.3 `string`

| Действие | Результат | Значение |
|---|---|---|
| `length()` | `int` | кодовые точки |
| `empty()` | `bool` | `length() == 0` |
| `slice(start, end)` | `string` | кодовые точки `start..end-1`; ошибка вне диапазона |
| `split(separator)` | `@string` | буквально; пустые поля сохраняются; `""` даёт кодовые точки |
| `replace(target, replacement)` | `string` | каждое непересекающееся вхождение |
| `replace_first(target, replacement)` | `string` | первое вхождение |
| `trim()`, `trim_start()`, `trim_end()` | `string` | пробельные символы с обоих краёв или с одного |
| `chomp()` | `string` | один завершающий перевод строки |
| `contains(part)`, `starts_with(part)`, `ends_with(part)` | `bool` | буквально |
| `find(part)`, `find_last(part)` | `Maybe<int>` | индекс в кодовых точках |
| `lower()`, `upper()` | `string` | стандартное преобразование регистра Unicode |
| `repeat(count)` | `string` | ошибка при отрицательном числе или результате больше 1 ГиБ |
| `characters()` | `@char` | кодовые точки |
| `less(other)`, `less_or_equal(other)` | `bool` | порядок кодовых точек |
| `order(other)` | `Order` | порядок кодовых точек |
| `string()` | `string` | сама строка |

`+` соединяет две строки; никакой другой тип со строкой не соединяется.

## B.4 Массивы `@T`

| Действие | Результат | Значение |
|---|---|---|
| `size()` | `int` | |
| `item(i)`, `xs[i]` | `T` | ошибка вне диапазона; `xs[i] else v` даёт `v` |
| `first()`, `last()` | `T` | ошибка на пустом массиве |
| `slice(start, end)` | `@T` | позиции; ошибка вне диапазона |
| `take(n)`, `drop(n)` | `@T` | не больше `n`; отрицательное `n` — ошибка |
| `reversed()` | `@T` | |
| `replaced(i, value)`, `removed_at(i)` | `@T` | копия, изменённая в одной позиции |
| `contains(value)` | `bool` | по `==` |
| `index_of(value)` | `Maybe<int>` | по `==` |
| `join(separator)` | `string` | массивы `string` |
| `ordering()` | `@T` | устойчивая сортировка по возрастанию через `Comparing` (импортируйте его) |
| `cursor()` | `Cursor<T>` | первая позиция (импортируйте `Cursor`) |

Функциональные операции `map`, `filter`, `reduce`, `any`, `all` и `find`
пишутся с блоком, `xs.map() -> x { … }` (раздел 8.2), и только эти имена
парсер принимает перед `->` в такой позиции. `+` соединяет два массива с
одним типом элементов, `-` удаляет каждый элемент, равный какому-нибудь
справа (`[1, 2, 1] - [1]` — это `[2]`), а диапазоны внутри литерала массива
разворачиваются: `[0, 2..=4]`. Приведение массива приводит каждый элемент:
`@float(xs...)`, `@string(1, 2.5)`, `@byte(255, 3)` и `@int(…)` принимают
позиционные значения и развёртки и отказывают на первом элементе, который не
приводится.

## B.5 Словари `%K:V`

| Действие | Результат | Значение |
|---|---|---|
| `size()` | `int` | |
| `has(key)` | `bool` | без чтения значения |
| `keys()` | `@K` | в порядке ключей |
| `values()` | `@V` | в порядке ключей |
| `m[key]` | `V` | ошибка для отсутствующего ключа; `m[key] else v` даёт `v` |

`map`, `filter` и `reduce` принимают `key, value` (`reduce` — сначала
аккумулятор), и `filter` даёт словарь. `m + ["k": v]` задаёт записи, а
`m - ["k": v]` удаляет их по ключу; значения справа не учитываются.

## B.6 `Future<T>`

| Действие | Результат | Значение |
|---|---|---|
| `done()` | `bool` | завершился ли |
| `cancel()` | `Future<T>` | просит остановиться; использование результата снимает обязательство must-use |
| `cancelled()` | `bool` | был ли отменён |

Значение достаётся только через `await` (глава 20).

## B.7 Функции приведения

Пять приведений пишутся и как функции: `int(x)`, `byte(x)`, `float(x)`,
`string(x)` и `char(n)` означают `x.int()`, `x.byte()`, `x.float()`,
`x.string()` и `n.char()`, причём функции принимают и значение, у которого
уже нужный тип (`string("s")`, `char('a')`), где метода нет.
`rat(numerator, denominator)` принимает два целых
и строит сокращённую дробь; один аргумент — ошибка, а `x.rat()` приводит одно
значение.
