# Native ABI

Общий контракт provider-вызовов для генератора и машины Sparrow. Crate не зависит от компилятора, IR,
машины, runtime-значений или внешних библиотек.

`Native` связывает канонический символ `модуль@major::имя/арность` со стабильным wire ID и сигнатурой
(`src/table.rs`, генерируется `tools/engines/gen-abi.py` из `std/runtime/*.ok`). Существующие ID нельзя
переименовывать или переиспользовать. SPB хранит символы, а не ID: машина находит натив по символу при
загрузке (`Native::resolve`). Символ, которого нет в таблице, компилируется, но его вызов отказывает во
время исполнения. Декларация исходника не может подменить сигнатуру provider.

Таблица перечисляет все нативы (569 на 0.6.4). `sparrow --native-capabilities` печатает их списком (JSON)
вместе с тем, есть ли каждый в этой сборке машины.

`catalogue` описывает то, чего в таблице нет: синхронный или асинхронный вызов (результат `Future`),
транспорт (данные, дескрипторы, `any`), роль дескриптора и эффект (чистое вычисление, стандартные потоки,
хост). После удаления движка Champ его читают только тесты.

`NativeFailure` сохраняет четыре поля языка: domain, code, operation, message. Это ожидаемый отказ
provider, а не повреждение машины.
