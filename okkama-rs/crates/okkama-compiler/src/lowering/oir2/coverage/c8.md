# C8: std source discovery and plain once slots

C8 is **blocked, not complete**. This is High producer work only. Every coverage
status remains `planned`; no executable or L09 acceptance is claimed. The
binding C8 decision at the top of the P2.3 plan takes precedence over its older
commit numbering.

## Implemented producer scope

- [x] Reachable ordinary std bodies use the existing C2 worklist and the same
      BodyLowerer as application code. This includes collections/list,
      collections/frequencies, collections/heap and collections/deque, with their
      iteration/view/size/compare/error dependencies. The original conformance
      harness is loaded from conformance/harness/okkama; no replacement harness
      or rewritten program is used. All case.json sources are analyzed as roots.
- [x] Requested method parameter signatures are substituted as well as results.
      Unrequested generic method signatures are not requested as executable
      concrete types. This fixes the ParamId(14) failure in Frequencies without
      discovering unused generic families.
- [x] Array-to-Iterating evidence and scalar-to-Comparing evidence have concrete
      C3 objects, constructors, witnesses and ordinary High bodies. Array cursors
      preserve their origin and position; exhaustion throws the actual std
      IterationEnded enum. These wrappers contain ordinary data, not intrinsic
      state. No native or external contract is added.
- [x] Builtin order produces compare.Order through scalar comparisons. Ordering
      calls an object's specialized C3 Comparing witness, with the ordinary
      failure envelope and unwind. Stable insertion sorting uses persistent
      array.replace and explicit loops, reusing the ordinary C6 joins and H5
      failure routes. This is O(n^2); no performance acceptance is claimed.
- [x] Specialization diagnostics now include the requesting function. Only the
      two existing generic-growth diagnostic goldens change as a consequence.

Unused imports do not force bodies: persistent-list imports collections/set,
heap and deque, but their unused bound actions and once slots are not discovered.
A reachable ordinary std action never becomes an invented external function.
Existing P1 registered stdout/UTF/error boundaries are unchanged. General native
ABI, closures/bound actions/any and async remain outside this producer slice.

## Once High form

- [x] Each reachable once-let site gets a deterministic hidden
      `$once<method>_<local>` field of concrete Maybe<T>, marked `once`.
      It is appended after source fields and before a possible $pending field.
      The text codec accepts these hidden field identifiers in both directions.
- [x] Constructors initialize every slot to Maybe.none. Successors explicitly
      stage and include none for every once field in obj.next; old receiver
      slots are not copied into the new identity.
- [x] once.load reads the slot, variant.tag selects some/none, and the some edge
      extracts the payload. The none edge computes the value normally, creates
      some and emits once.store only on successful completion. Both successful
      edges join before the one lexical bind for the once local.
- [x] Calls and failures retain the existing H5 unwind and D11 machinery. A
      failing computation cannot reach once.store on its unwind edge.
- [x] A producer rejection catches known resource graphs in once fields,
      including concrete generic aggregates and reachable resource-bearing role
      implementations. This is not a #565 ownership/plain certificate.
- [x] The unmodified ownership corpus once-generic.ok and once-role.ok still fail
      the public frontend check with a semantic resource-storage diagnostic,
      not Unsupported or a loader error. High separately rejects them as
      InvalidThir. The frontend and its rules have not changed.

| L09.compare.failing-order-stops-the-sort | Lowers to High; independent verification is Incomplete at the default memory budget, without semantic diagnostics; the small failing-comparator golden is verified |

The B11.1 cause is the existing verifier's managed_types implementation in
okkama-oir/src/verify/linearity/metadata.rs: Type::Role is unconditionally managed.
It cannot establish plainness from the closed set of concrete plain witnesses.
Frequencies.counted caches List<Frequency<string>>; Heap.planted caches
HeapRepresenting<int>; Deque.split caches DequeParts<int>, whose fields reach
List<int>. These are not replaced with recomputation or another cache type.

The memory-limited checks use the default 256 MiB budget. Incomplete is a blocker,
never a certificate. No verifier limit, verifier source or own source changes
are made. Completing those two std programs requires the #565 plain-graph gate;
the large sorting program additionally needs verification within its budget.
